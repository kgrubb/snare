snare

Helm chart for the Netgear Plus SNMP facade

Add repository

helm repo add kgrubb-snare https://kgrubb.github.io/snare
helm repo update

Install

helm install snare kgrubb-snare/snare \
  -n snare --create-namespace \
  --set config.switch.url=http://192.168.1.205 \
  --set config.switch.password=changeme
